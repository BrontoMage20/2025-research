# 2025-research
Documentation of the code used for my 2025 research project.

Title of research project: A Statistical Comparison of Execution Performance in Selected Steganalysis Tools

It also includes the data acquired during the summer of 2026 for the submission to NHSJS, along with a helpful little file called "zsh-corrupt-history-fix-commands.sh". Sadly, it does not work as a .sh file, but the individual lines will work when run through the CLI.

The folder "25-image-set" was used for Set 1.
The folder "stuff for the set of 50 images" was used for Set 2, Trial 0.
The folder "stuff for randomized trials" was used for Set 2, Trials 1-3.
